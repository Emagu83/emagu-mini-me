# EMAGU Mini Me — PWA 0.1

Pacchetto PWA da pubblicare su hosting HTTPS.

## Pubblicazione con GitHub Pages
1. Crea un repository GitHub pubblico `emagu-mini-me`.
2. Carica tutti i file e la cartella `icons` nella radice.
3. In Settings → Pages seleziona Deploy from a branch, `main`, `/ (root)`.
4. Apri l'indirizzo HTTPS generato.

## Installazione su iPhone
1. Apri l'URL HTTPS con Safari.
2. Tocca Condividi → Aggiungi alla schermata Home.
3. Conferma Aggiungi.

## Limiti
Dati locali nel browser, senza sincronizzazione/account. Avatar dimostrativo emoji, non 3D. Nessuna notifica programmata, AI online o pubblicità. Non è ancora un'app nativa da App Store/Google Play.
